## 1. 목적 및 핵심 사용자 시나리오

가구(우리집) 구성원이 하나의 장보기 리스트를 실시간으로 공유하며, **누군가 이미 구매한 품목을 즉시 표시하여 다른 가족이 중복 구매하지 않도록 방지**하는 기능입니다.

### 핵심 시나리오
1. **장보기 품목 등록**: 가족 구성원 중 한 명이 떨어져 가는 식재료(예: `서울우유 1L`, `계란 30구`)와 수량·단위·메모를 장보기 리스트에 추가합니다.
2. **마트에서 확인 및 구매 완료 표시**: 먼저 장을 본 가족이 리스트에서 해당 품목을 체크하면 `구매 완료` 상태로 전환되며, **구매자 닉네임과 구매 시각**(예: `민지님 구매 완료 · 14:20`)이 기록됩니다.
3. **중복 구매 방지**: 다른 가족이 뒤늦게 마트에 가거나 장보기 리스트를 열었을 때, 이미 구매 완료된 품목은 **취소선 + 구매자 배지**와 함께 리스트 하단 `구매 완료` 섹션에 유지되어 **"이미 샀으니 안 사도 된다"**는 것을 즉시 확인할 수 있습니다.
4. **구매 취소 및 정리**:
   - 실수로 체크한 경우 다시 탭하여 미구매 상태로 되돌릴 수 있습니다.
   - 장보기가 모두 끝난 후에는 개별 삭제 또는 `구매 완료 비우기`로 완료 항목을 일괄 정리할 수 있습니다.

## 2. 데이터 모델 및 상태 규칙

### 2.1 가구 단일 공유 리스트
- 별도의 장보기 리스트 묶음(폴더) 없이 **가구당 하나의 공유 장보기 리스트**를 운영합니다.
- 모든 `MEMBER` 이상 가구 구성원이 품목을 추가, 수정, 구매 완료/취소 토글, 삭제할 수 있습니다.

### 2.2 품목 필드
| 필드 | 타입 | 필수 | 설명 |
|---|---|---|---|
| `name` | `String(150)` | 필수 | 품목명 (예: `대파`, `두부 1모`) |
| `category` | `String(30)` | 선택 | `FRESH`, `MEAT_FISH`, `DAIRY`, `PROCESSED`, `BEVERAGE`, `SAUCE`, `ETC` (기본 `ETC`) |
| `quantity` | `Numeric(10, 2)` | 선택 | 구매 예정 수량 (기본 `1.00`, `> 0`) |
| `unit` | `String(30)` | 선택 | 단위 (기본 `개`) |
| `memo` | `String(500)` | 선택 | 브랜드/용량/메모 (빈 문자열은 `NULL` 정규화) |
| `is_purchased` | `Boolean` | 자동 | 구매 완료 여부 (기본 `false`) |
| `purchased_by` | `BigInt` | 자동 | 구매 완료 처리한 사용자 ID (`is_purchased=true` 시 기록, 취소 시 `NULL`) |
| `purchased_by_nickname` | `String` | 응답 | 구매자 닉네임 (UI 표시용) |
| `purchased_at` | `DateTime(TZ)` | 자동 | 구매 완료 시각 UTC (`is_purchased=true` 시 기록, 취소 시 `NULL`) |

### 2.3 정렬 및 표시 정책
- **상단 (`살 것` / 미구매)**: `is_purchased = false` 항목을 최신 등록순(`created_at DESC, id DESC`)으로 표시합니다.
- **하단 (`구매 완료`)**: `is_purchased = true` 항목을 최근 구매순(`purchased_at DESC, id DESC`)으로 구분선 아래에 유지합니다.
- 구매 완료 항목은 삭제되기 전까지 리스트 하단에 남아, 다른 구성원이 구매 여부를 확인할 수 있습니다.

## 3. UI/UX 규칙 (Fresh Kitchen Material)

- **하단 네비게이션**: 기존 `재고·장소`, `가족·알림` 사이에 **3번째 중앙 탭 `장보기`** (`Icons.Outlined.ShoppingCart` / `Icons.Rounded.ShoppingCart`)를 배치합니다. (미구매 항목이 있을 경우 배지 점 또는 카운트 표시)
- **미구매 카드**:
  - 좌측 체크박스(또는 원형 체크 버튼) + 품목명 + 수량/단위 필(`1 팩`) + 카테고리 태그 + 메모.
  - 우측 수정/삭제 액션.
- **구매 완료 카드**:
  - `SurfaceSubtle`(`#F1F5F9`) 톤의 차분한 카드 배경, 체크된 `#00685F` 아이콘, **취소선(`TextDecoration.LineThrough`)** 품목명.
  - **구매자 배지**: `#CCFBF1` 배경 / `#00685F` 텍스트 필 형태로 `"{닉네임}님 구매 완료 · HH:mm"` 표시.
