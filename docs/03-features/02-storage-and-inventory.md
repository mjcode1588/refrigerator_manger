## 1. 자유 트리 보관 장소 관리

가정마다 냉장고, 김치냉장고, 팬트리, 베란다 선반 등의 구조가 다르므로 **깊이 제한 없는 자유 트리 구조**를 제공합니다.

### 1.1 트리 예시
```text
🏠 우리집
├── 🧊 주방 양문형 냉장고
│   ├── ❄️ 냉동실
│   │   ├── 상단 선반
│   │   └── 하단 서랍 (육류)
│   └── 🥗 냉장실
│       ├── 야채칸
│       └── 문쪽 선반 (음료/소스)
├── 🥬 김치냉장고
│   └── 중칸
└── 📦 팬트리
    ├── 1단 선반 (라면/통조림)
    └── 2단 선반 (과자/음료)
```

### 1.2 핵심 기능 요구사항
- **생성/수정**: 보관 장소 이름, 유형(`FRIDGE`, `FREEZER`, `PANTRY`, `ROOM_TEMP`, `CUSTOM`), 아이콘, 정렬 순서(`sort_order`) 설정.
- **이동(Reparenting)**: 특정 보관 장소를 다른 보관 장소의 하위로 이동하거나 최상위(Root)로 승격 가능.
  - **제약**: 자기 자신 또는 자신의 하위 노드를 부모로 지정할 수 없음 (`LOCATION_CYCLE_DETECTED`).
  - **권장 UX 깊이**: 기술적으로는 무제한이나, 모바일 화면 가독성을 위해 5단계 이상 중첩 시 UI에서 브레드크럼(Breadcrumb) 경로 축약 표시(`... > 냉동실 > 하단 서랍`).
- **삭제 정책**: 하위 보관 장소나 보관 중인 품목(`ACTIVE`)이 존재할 경우 실수 방지를 위해 3가지 중 선택:
  1. `restrict` (기본값): 하위 항목이 있으면 삭제 거부
  2. `move`: 하위 장소/품목을 지정한 다른 장소(또는 상위 장소)로 이동 후 삭제
  3. `cascade`: 하위 장소 및 소속 품목 일괄 삭제 (2차 확인 다이얼로그 필수)
- **하위 포함 조회**: `주방 양문형 냉장고`를 선택하면 해당 장소와 모든 하위 구역의 품목을 한 번에 볼 수 있는 토글(`하위 구역 포함`) 제공.

## 2. 식재료 및 완제품 재고 관리

### 2.1 품목 속성
| 필드 | 필수 | 설명 |
|---|:---:|---|
| `name` | O | 품목명 (예: 대파, 신라면 5입, 코카콜라 제로) |
| `location_id` | O | 보관 장소 ID (트리의 어느 노드에든 배치 가능) |
| `category` | O | 신선식품, 육류/수산, 유제품, 가공/완제품, 음료, 양념/소스, 기타 |
| `quantity` / `unit` | O | 수량(소수점 허용, 예: `1.5`) + 단위(개, 팩, 병, g, kg, ml, 봉 등 자유 입력/프리셋) |
| `expiry_date` | X | 유통기한 또는 소비기한 (`YYYY-MM-DD`) |
| `expiry_type` | O | `USE_BY`(소비기한), `BEST_BEFORE`(유통기한), `NONE`(기한 없음) |
| `memo` | X | 구매처, 개봉일, 보관 팁 등 자유 메모 |

### 2.2 빠른 재고 액션 (모바일 UX 최적화)
- **빠른 수량 조절**: 리스트 카드에서 `-` / `+` 버튼으로 수량을 즉시 조정 (수량이 `0`이 되면 "소비 완료 처리할까요?" 스낵바/팝업 제안).
- **부분 소비 / 전량 소비**: 예) `우유 2팩` 중 `1팩` 소비 시 수량만 `1팩`으로 차감하고 이력에 기록; 전량 소비 시 `status = CONSUMED`로 전환.
- **폐기 처리**: 상했거나 기한이 지나 버린 품목은 `status = DISCARDED`로 처리하여 소비와 구분.
- **보관 장소 이동**: 예) 냉장실에 있던 고기를 냉동실로 옮길 때 트리 피커(Picker)로 1~2탭 만에 이동.

### 2.3 검색 및 필터링
- **검색**: 품목명 및 메모 키워드 검색 (Room 로컬 캐시 기반 즉시 필터링 + 서버 검색).
- **필터**: 보관 장소(하위 포함), 카테고리, 상태(`보관 중` / `소비 완료` / `폐기`), 기한 상태(`만료` / `임박` / `여유` / `기한 없음`).
- **정렬**: 유통기한 임박순(기본값, 기한 없는 품목은 하단 배치), 최근 등록순, 이름순.
